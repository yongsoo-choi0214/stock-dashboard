## 0. 30초 사용법

1. **맨 위 한 줄 요약**만 봐도 오늘 상태가 다 나옵니다
2. 색이 🔴 인 항목이 있으면 그 탭으로 들어갑니다
3. 그게 전부입니다

나머지는 궁금할 때 파고드는 용도입니다.

## 1. 상단 한 줄 요약

```
🟢 KOSPI 6,579 (+3.7%) · 🔴 고점 대비 -27.8% · ⚪ 취약성 적용 밖 ·
🔴 레짐 수축 (11일째) · 🟡 외국인 5일 -27,563억 · 🟡 신용스프레드 0.71%p ·
🟢 장단기 +0.50%p · 🟡 BSI 77 (비관 우위)
```

| 색 | 뜻 |
|---|---|
| 🟢 | 정상 |
| 🟡 | 주의 |
| 🔴 | 경계 |
| ⚪ | **판단 불가** — 숫자를 내밀지 않습니다 |

**⚪ 가 나오면 그 지표는 지금 해석하면 안 된다는 뜻**입니다. 예를 들어
취약성 지수는 "고점에서 이제 빠질까"를 재는 것이라, 이미 30% 빠진 자리에서는
의미가 없습니다. 그럴 때 억지로 숫자를 보여주면 잘못 읽게 됩니다.

### 그 아래 갱신 배지

```
🟢 ecos 2026-08-13 19:13 · ~2026-08-12   🔴 krx_flow ...
```

- 앞의 날짜 = **언제 수집했나**
- `~` 뒤의 날짜 = **데이터가 어디까지 있나**
- 🔴 이면 그 소스가 실패한 것 — 화면의 해당 부분이 낡았을 수 있습니다

> 갱신 시각을 안 보여주는 대시보드는 믿을 수 없습니다. 화면이 멀쩡해 보여도
> 데이터가 한 달 전 것일 수 있으니까요.

## 2. 탭별 안내

### 개요
지수 하나를 골라 **가격 · MACD · RSI** 를 3단으로 봅니다. 사이드바에서
RSI 기간과 MACD 파라미터를 바꿀 수 있습니다.

### 한국 시장
- **이격도** — 이동평균 대비 위치
- **밸류에이션** — PER/PBR/배당수익률 + **252일 백분위**
- **한국 유동성** — 예탁금, 예탁금/시총
- **투자자별 수급** — 개인·외국인·기관·기타법인 (일간/주간/월간)

### 유동성
- **미국 순유동성** vs 지수
- **한국 금리 · 크레딧** — 국고채 커브, 신용스프레드
- **실물** — 수출 YoY, BSI
- 기타 매크로 16종 선택

### 크로스에셋
- 상대 성과 (시작 = 100)
- **상관 히트맵** — 시차 정렬 토글 주의 (§4 참조)

### 연구
- 지표별 **IC**(정보계수)
- **유동성 × 모멘텀 레짐**
- **취약성 지수** + 검증
- **변동성 레짐**, **월별 계절성**
- **기록 이력** — 그날 실제로 뭐라고 했는지

### 데이터
- 계열 카탈로그 (검색 가능)
- CSV 내려받기

## 3. 반드시 알고 봐야 할 것 세 가지

### ① 취약성 지수는 "고점 근처"에서만 유효합니다

고점 대비 **-10% 이내**일 때만 의미가 있습니다. 그 밖에서는 화면이
"적용 밖"이라고 표시합니다.

이유는 측정으로 확인했습니다 — 조건 없이 쓰면 IC **-0.126**, 고점 근처로
한정하면 **-0.434** 로 세 배 차이가 납니다. 지수가 높은 날의 상당수가
**이미 폭락이 진행 중인 날**이었기 때문입니다.

> "고점에서 이제 빠질까"와 "이미 30% 빠진 자리에서 더 빠질까"는 다른
> 질문입니다.

### ② 이 지표는 예측이 아니라 **확률을 기울이는 게이지**입니다

8번의 조정 고점에서 실제로 어땠는지 화면에 그대로 띄웁니다 —
**경보 3회 / 무신호 5회**. 절반쯤 놓칩니다.

조건부 분포(1분위는 -10% 낙폭 0건, 4분위는 42%)는 뚜렷하게 갈리지만,
고점 시점을 짚는 능력은 그렇지 않습니다. **둘 다 사실입니다.**

8번을 다 맞혔다면 오히려 미래 정보가 샜다고 의심해야 합니다.

### ③ 표본은 21.6년에 조정 8회뿐입니다

이 숫자가 모든 분석의 천장입니다. 지표를 더 넣는다고 나아지지 않습니다 —
실제로 후보 11개를 시험했을 때 기존과 비슷한 축은 **6개 전부 실패**했고,
성격이 다른 축(금리커브·수출·레버리지·밸류·크레딧)만 통과했습니다.

## 4. 흔한 오해

| 오해 | 사실 |
|---|---|
| "상관이 낮으니 미국과 무관하네" | **시차 정렬을 켜세요.** 한국장은 15:30 에 닫고 미국장은 그 뒤에 열립니다. 같은 날로 비교하면 SOX 0.15, 정렬하면 0.40 입니다 |
| "PER 17 이면 싸다/비싸다" | 레벨만으로는 알 수 없습니다. **백분위**를 보세요 |
| "변동성이 높으니 위험하다" | 과거에는 **반대**였습니다. 변동성 5분위의 향후 60일 수익률이 +7.78%, 상승확률 76% 입니다 (공포 뒤 되돌림) |
| "월간 데이터가 낡았다" | 한국 M2 는 원래 **2개월 지연** 공표입니다. 데이터 탭의 지연 경고에서 월간 계열은 정상입니다 |
| "5월에 팔아라" | KOSPI 에서는 데이터에 없습니다. 나쁜 달은 **8월(-1.32%)** 과 10월입니다 |

## 5. 용어 사전

### 유동성

| 용어 | 뜻 |
|---|---|
| **순유동성** | 연준 총자산 − 재무부 일반계정(TGA) − 역레포(ON RRP). 시중에 실제로 풀린 돈. 단위 십억 USD |
| **TGA** | 미 재무부가 연준에 둔 계좌. 여기 쌓이면 시중에서 돈이 빠진다 |
| **ON RRP** | 익일물 역레포. 금융기관이 연준에 하루 맡기는 돈. 늘면 시중 유동성이 준다 |
| **예탁금** | 투자자가 증권사에 넣어둔 대기 자금. 월간 |
| **예탁금/시총** | 시장 규모 대비 대기 자금 비율 (%) |
| **신용융자** | 빚내서 산 주식 잔고. 조정을 증폭시킨다 |

### 금리 · 크레딧

| 용어 | 뜻 |
|---|---|
| **장단기 스프레드** | 국고채 10년 − 3년. **0 아래면 역전**이고 전통적인 침체 선행 신호 |
| **신용스프레드** | 회사채 AA- − 국고채 3년. 우량 기업의 자금조달 비용 |
| **저신용 스프레드** | 회사채 BBB- − 국고채 3년. 구조적으로 6%p 대라 위 차트와 따로 그린다 |
| **CP-CD 스프레드** | 기업어음 − 양도성예금증서(둘 다 91일물). 단기자금 경색 신호 |
| **BAA10Y** | 무디스 Baa 회사채 − 미 10년물. 미국판 신용스프레드 |

### 지표

| 용어 | 뜻 |
|---|---|
| **RSI** | 0~100. 70 이상 과매수, 30 이하 과매도. Wilder 방식(α=1/n) |
| **MACD** | 단기·장기 이동평균 차이. 히스토그램이 0 위면 상승 우위 |
| **이격도** | 종가 ÷ 이동평균 × 100. 100 이면 이동평균과 같음 |
| **백분위** | 최근 252일 중 지금이 몇 % 위치인가. 0.8 = 상위 20% |
| **z-score** | 평균에서 표준편차 몇 배 떨어져 있나 |

### 연구

| 용어 | 뜻 |
|---|---|
| **IC** (정보계수) | 신호와 이후 수익률의 순위상관. **0.1 만 넘어도 의미 있고**, 0.3 이 넘으면 미래 정보 유입을 의심해야 한다 |
| **표본 내 / 표본 외** | 앞 구간에서 정하고 뒤 구간에서 검증. 두 값이 비슷해야 과적합이 아니다 |
| **walk-forward** | 시간 순서를 지켜 앞으로만 검증하는 방식 |
| **look-ahead bias** | 그때 알 수 없었던 정보를 쓰는 오류. 백테스트가 실제보다 좋아 보인다 |
| **point-in-time** | 그 시점에 실제로 볼 수 있었던 값. 정정 전 원본 |
| **레짐** | 유동성 변화 × 모멘텀 4분면 (확장/회복시도/후퇴/수축) |
| **취약성 지수** | 10개 컴포넌트의 롤링 백분위 평균 [0,1]. 높을수록 취약 |
| **최대낙폭 (MDD)** | 고점 대비 가장 깊이 빠진 폭 |
| **분산 매도일** | 지수는 내렸는데 거래량이 늘어난 날. 기관 매도 흔적 (O'Neil) |
| **시장 폭 (breadth)** | 몇 %의 업종/종목이 함께 오르는가. 지수만 오르면 위험 신호 |

### 수급

| 용어 | 뜻 |
|---|---|
| **순매수** | 매수 − 매도. 양수면 사들인 것 |
| **외국인합계** | 외국인 + 기타외국인 |
| **기관합계** | 금융투자·보험·투신·연기금 등 |
| 합계가 0 | 네 구분의 순매수를 더하면 **항상 0**. 한쪽이 사면 다른 쪽이 판다 |

|---|---|---|
| 저녁 | 월~금 **18:00** | 한국 지수·수급·환율 (당일) |

알림은 텔레그램으로 오며, **상태가 바뀔 때만** 울립니다. 같은 상태가
이어지는 동안은 조용합니다.

## 7. 문제가 생기면

| 증상 | 확인 |
|---|---|
| 화면에 빨간 오류 상자 | 다른 탭은 살아 있습니다. 오류 메시지의 마지막 줄을 확인하세요 |
| 갱신 배지가 🔴 | 그 소스만 실패. `data/_meta.json` 에 사유가 있습니다 |
| 특정 패널만 "데이터 없음" | 해당 ETL 을 돌리세요: `python -m src.etl.run_all --only ecos` |
| 값이 이상하다 | 데이터 탭에서 CSV 를 받아 직접 확인하세요 |

로컬에서 확인:

```bash
.venv/Scripts/python.exe -m src.etl.check_keys     # 키 상태
.venv/Scripts/python.exe -m src.alerts.run --dry-run  # 지금 뭐가 울릴지
.venv/Scripts/python.exe -m pytest -q               # 전체 검증
```
